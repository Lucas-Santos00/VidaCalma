## 📋 Sobre o Projeto
Este projeto é uma **Landing Page** para divulgação e captação de leads para o ebook *Vida Calma*, que aborda estratégias e dicas para lidar com a ansiedade.  

O **design foi fornecido por um terceiro (cliente)** e todo o **desenvolvimento** foi feito por mim, utilizando apenas **HTML e CSS** para garantir leveza e compatibilidade com diversos dispositivos.

[Live demo](https://lucas-santos00.github.io/VidaCalma/)

---

## 🚀 Tecnologias Utilizadas
- **HTML5** – Estrutura semântica da página.
- **CSS3** – Estilização e responsividade.

---

## ✨ Funcionalidades
- 📱 Layout responsivo adaptado para desktop e mobile.
- 🎨 Fiel ao design fornecido pelo cliente.
- ⚡ Carregamento rápido e otimizado.
- 📌 Estrutura voltada para conversão de leads.
